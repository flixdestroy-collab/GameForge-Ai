## ✨ What is GameForge AI?

GameForge AI is a creator hub designed to help Roblox developers move from an idea to a structured game project. Use AI-assisted workflows to plan your experience, work through game systems, and prepare development tasks for Roblox Studio.

## 🧠 Two ways to create

| Tool | What it helps with |
| --- | --- |
| 🛠️ **Build with Help** | Get guidance, ideas, explanations, and Roblox Luau script examples while you build your game yourself. |
| 🤖 **Make it for Me** | Turn a game idea into a more complete structured creation plan and guided build workflow. |

## 🚀 Getting started

1. Visit [GameForge AI](https://gameforge-ai-seven.vercel.app/).
2. Choose the creation workflow that matches how you want to work.
3. Describe your game idea, genre, gameplay, and important features.
4. Review the generated guidance and refine your plan.
5. Use Roblox Studio to build, test, and improve your experience.

> Roblox Studio is required to create and publish Roblox experiences. GameForge AI does not replace Roblox Studio.

## 🧩 Roblox Studio plugin

The GameForge Roblox Studio plugin is intended to connect the website's creator workflow with Roblox Studio.

**Plugin package status:** The downloadable ZIP is being prepared for this public repository. We will publish the verified package here when it is ready. Please do not download or run unofficial copies claiming to be the GameForge plugin.

## 🔐 Safety and project quality

- Review AI-generated scripts before using them in a live experience.
- Test changes in a separate Roblox Studio test place before publishing.
- Never share passwords, account cookies, API keys, or private credentials in issues.
- Only download plugin releases linked from this repository or the official GameForge website.

## 🌟 Community

GameForge improves through useful feedback from creators. Open an issue to report a reproducible bug or suggest a feature. Please be respectful and include enough detail for others to understand the request.
