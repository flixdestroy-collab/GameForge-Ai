# 🤝 Contributing to GameForge AI

Thanks for helping improve GameForge AI!

## Ways to contribute

- 🐞 Report bugs with clear reproduction steps.
- 💡 Suggest creator-focused features.
- 📚 Improve setup guides and documentation.
- 🧪 Test workflows and share what worked or did not work.

## Before opening an issue

1. Search existing issues to avoid duplicates.
2. Use a clear, descriptive title.
3. Include the page or workflow involved.
4. Describe what you expected and what happened.
5. Include screenshots only after removing personal information.

## Safety and privacy

Never post passwords, Roblox account cookies, API keys, private tokens, email verification codes, or other credentials. Do not upload private user data.

## Pull requests

Keep changes focused, explain why they help creators, and include testing notes. Documentation improvements are welcome.

Be respectful and constructive. Harassment, spam, and sharing unsafe files are not welcome.
