# 🧭 Getting Started with GameForge AI

Welcome to GameForge AI! This guide walks through the basic creator workflow.

## 1. Open the website

Visit [GameForge AI](https://gameforge-ai-seven.vercel.app/).

## 2. Choose a creation workflow

- **🛠️ Build with Help:** use AI guidance, explanations, and script examples while you build.
- **🤖 Make it for Me:** develop a structured plan for a Roblox experience and follow the guided creation workflow.

## 3. Describe your game

Useful details include:

- 🎯 The main goal players should achieve
- 🔁 The core gameplay loop
- 🗺️ The map, world, and locations
- 🧑‍🤝‍🧑 Solo, co-op, or multiplayer plans
- 📈 Progression, upgrades, and rewards
- 🎨 Art direction and atmosphere
- 🎮 Controls and target devices

Start with the core idea. Add detail in later prompts rather than trying to specify everything at once.

## 4. Build and test in Roblox Studio

Use Roblox Studio to create the place, inspect scripts, test gameplay, and refine the experience. Test changes in a separate test place before publishing.

## 5. Get help

- [Open an issue](../issues) for a reproducible bug or feature request.
- [Read plugin information](STUDIO_PLUGIN.md).
- [Visit the official site](https://gameforge-ai-seven.vercel.app/).

> AI-generated code is a starting point. Review and test scripts before using them in a published experience.
