# 🧩 GameForge AI Roblox Studio Plugin

The GameForge Studio plugin is designed to connect the GameForge creator workflow with Roblox Studio.

## Intended workflow

1. Open the GameForge AI website and Roblox Studio.
2. Connect the Studio plugin to the creator session when the verified release is available.
3. Prepare a game build plan through the website.
4. Review the proposed changes in Studio.
5. Test the result in a safe test place before publishing.

## 📦 Download status

**Security note:** Do not run plugin files from unofficial mirrors or share Roblox passwords, session cookies, or account credentials with anyone.

## Requirements

- Roblox Studio on a supported desktop operating system.
- A GameForge AI account/session if required by the current website workflow.
- A test place for checking generated changes before publishing.

Roblox Studio is not available as a full development environment on iPhone or iPad.
