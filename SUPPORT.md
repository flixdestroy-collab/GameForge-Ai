- 💡 [Suggest a feature](../../issues/new?template=feature_request.md)

## What to include in a support request

- Which page or feature you were using
- What you were trying to do
- What happened instead
- Any error message (remove private information first)
- Your device and browser or Roblox Studio version, if relevant

## Keep your account safe

GameForge support will never need your Roblox password, account cookie, two-step verification code, or payment details. Never post those in an issue or send them to another user.

## Plugin downloads

Only use the verified plugin package linked from the official GameForge website or this repository's Releases page. If no release is listed, the package is not ready yet.
